# hoshiya's shitty dotfiles™

Managed with [Chezmoi](https://www.chezmoi.io/)

## Setup Overview

- **Terminal**: Foot (current), Alacritty
- **Application Launcher:** Fuzzel
- **Editor:** Neovim
- **Compositor:** Hyprland (current), Niri
- **Keyboard Remapper:** Kanata
- **PDF Reader:** sioyek (Although I use Okular much more often)
- **Notification Center:** SwayNC
- **Status Bar:** Waybar
- **Logout Menu:** wlogout
- **MISC:** [Hexecute](https://github.com/ThatOtherAndrew/Hexecute)
- **Shell:** zsh
    - **Plugin Manager for zsh:** Antidote
- **RSS Reader:** Newsboat
- **Multiplexer:** TMUX
    - **Plugin Manager for TMUX:** [TPM](https://github.com/tmux-plugins/tpm)
- **Wallpaper:**
    - **Wallpaper Setter:** Waypaper
    - **Backend:** awww


## Installation 

Install chezmoi with your preffered package manager

```bash
chezmoi init --apply https://github.com/hoshiya4522/dotfiles.git
```

> [!NOTE]
> Old dotfiles can be found on the [legacy](https://github.com/hoshiya4522/dotfiles/tree/legacy) branch

> [!TIP]
> Install the entire configuration can be installed with Arch Linux using [HADBADS](https://github.com/hoshiya4522/HADBADS)
